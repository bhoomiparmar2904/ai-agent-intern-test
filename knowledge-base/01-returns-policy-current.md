# Returns Policy (Current)

## Standard return window
Standard-tier customers may return an unused, unworn item within **30 calendar days** of
delivery for a full refund to the original payment method.

## TrailPlus members
TrailPlus members receive an extended window; see `09-trailplus-membership.md`.

## Condition requirements
Items must be unused, with original tags and packaging, unless the item arrived damaged or
incorrect (see `04-damaged-or-wrong-items.md`).

## Final-sale items
Final-sale items are not eligible for standard returns. See
`03-final-sale-and-promotions.md` for exceptions related to damaged or incorrect items.

## Exceptions require human review
Any return outside these standard terms (extended windows, goodwill exceptions, or a policy
override referenced from another internal document) requires human support review before
approval. The agent cannot approve a return on its own.
